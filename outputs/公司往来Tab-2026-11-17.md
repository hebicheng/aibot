# 公司往来 Tab（2026-11-17）

## 功能
左侧导航「对账台账」与「市场行情」之间新增 **公司往来**，展示本公司与供货商的发票往来。

| 指标 | 口径 |
|---|---|
| 采购材料总额 | 已确认采购单金额合计（与台账「采购金额」同口径，不含运费） |
| 已开发票金额 | 已确认入账的进项发票价税合计 |
| 未开发票金额 | 采购总额 − 已开发票；为负表示发票多于采购，标红提示 |

- **统计范围**：全部项目 / 单个项目。
- **按供货商汇总**：每家供货商的采购额、已开票、未开票、开票进度；点击某行可筛选下方发票列表。
- **发票列表**：开票日期、发票号码、供货商、项目/批次、价税合计、税额、税率、状态；可查看原件、删除。
- **上传发票**：选择发票所属项目和批次后上传（图片 / PDF / OFD / XML，可多选），走智能助理识别，识别结果出现在列表里为「待确认」，点「确认入账」后计入已开票金额并同步台账。
- **重复发票**：同一张发票重复上传会标记「疑似重复」，可选「保留」或「跳过」；跳过的不计入、不展示。
