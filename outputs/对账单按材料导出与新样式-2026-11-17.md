# 对账单：按材料导出 + 客户钢材对账单样式

## 完成内容

### 1. 按批次材料筛选导出
- 导出时可以选「材料」：选项 = 项目里各批次**新建时填写的材料**（去重），外加「全部材料」。
- 选了「螺纹钢」后，只导出材料为螺纹钢的那些批次里、日期范围内的送货单。
- 同一筛选口径贯穿整张单：明细、合计、**累计供应量 / 累计供货金额**、**本次 / 累计已支付**（只取分摊到这些批次的收款）都只统计这些批次，不会混进别的材料的数。
- 四个导出入口都已加材料选择：Web 台账页弹框、Web 聊天卡片、小程序台账页、小程序聊天卡片。

### 2. 对账单样式改成客户样表
- 抬头：`{客户单位}钢材对账单`；日期改成 `2025年12月1日——2026年9月30日`。
- 合同名称固定「无合同」，供应商名称取当前账号的单位名称。
- 明细 10 列：序号 / 钢材名称 / 规格型号 / 数量（吨）/ 网价 / 上浮额 / 计量单价 / 小计 / 日期 / 备注。
  - 钢材名称拆成「大类 + 换行 + 牌号」，如「螺纹钢 / HRB400E」；规格型号写「直径*定尺」，如「18*9」，盘螺只写直径。
  - 日期写「M月d日」，**同一天只在第一行写**，与样表一致。
  - 客户承担的运费**单独成一行「运费」**，金额计入小计和合计，不计入数量。
- **备注不再放送货单图片，改为显示产地/品牌**（如 中天、芜湖富鑫、西城）。

## 运费的分摊规则
- 送货单上写明的运费：跟在那张送货单后面。
- 按吨口径：按这张送货单的吨数 × 单价。
- 按趟包干：一个批次只算一次，挂在该批次最早的那张送货单后面；分段导出时不会每段都重复计。

## 需要知道的口径
- **材料按批次匹配**：看的是批次上填写的材料文字，要求完全一致（首尾空格忽略）。如果某批次写的是「钢筋」，它就不会出现在「螺纹钢」里。
- **产地/品牌**来自送货单明细的「产地」字段；识别时没识别出来的行，备注为空。
- **规格拆分**依赖规格里有「直径*定尺」或 Φ 写法；拆不出时原样显示规格。
