# 运费口径审计与新架构全局遗留报告（2026-11-04）

## 一、运费现状（代码核实的事实链路）

### 1.1 采购运费（我们付给承运方的钱）

| 环节 | 现状 |
|---|---|
| **数据载体** | ⚠️ 挂在**送货单**上：`structuredData.transportFee`（`transportFeeSource=batch_hint` 标记口径补的值）。采购单本身不承载采购运费 |
| **默认补值** | 送货单**创建时** `applyFreightHintDefaults`：批次口径 perTrip 直接填 / perTon×计价吨数；说明里提到运费则跳过。重算时 `applySupplyFreightDefault` **只覆盖 batch_hint 来源的值**，单据实际抽到的永不覆盖；口径清空会连带撤掉补的值 |
| **台账入账** | 送货单确认/重算 → `deliveryFreightAmount` 并入 `LedgerRecord.freight`（台账「运输费用」列，未付款基线=采购+运费−已付 也含它）；运输单则整单金额并入 freight |
| **采购毛利率** | `batchFreightCost` 三级优先：①运输单合计 → ②送货单 transportFee 合计 → ③**批次口径推算**（perTrip×送货单张数 / perTon×采购吨数）；采购成本=材料采购额+运费 |
| **材料层** | 运费不进材料层、不进采购吨价（正确：毛利点数只对货价） |

### 1.2 销售运费（客户承担）

送货单 `salesFreight` 列，进销售总额、进毛利率分母（总额法）；批次口径变更时 `resyncDeliverySales(forceFreight=true)` 覆盖补值。链路自洽，无问题。

### 1.3 你问的问题，答案

**①「批次有采购运费口径时，采购侧计算默认算了运费但没有运费行」——是，而且比你想的多一层：**

- 台账「采购运费成本」列（采购毛利率用）会按口径推算扣减 ✓；
- 但台账「运输费用」列（`LedgerRecord.freight`）**只累计送货单 transportFee 和运输单，不做口径推算**；
- 两个口径只在「口径推算值被 applyFreightHintDefaults/applySupplyFreightDefault 落到某张送货单并确认之后」才重新一致。**口径先配、送货单还没确认/还没被 resync 补值**的窗口里：采购毛利率扣了运费，运输费用列和未付款基线都没算——同一笔钱一个口径算、一个不算；
- 且这行推算值在界面上只有列头 tooltip 一句话解释，没有来源明细（不知道是口径推的还是哪张单来的）。

**②「送货单卡片上出现采购运费」**——是历史建模怪点：进项运费寄生在销售侧单据上（因为一车货采送同拍）。新架构下这是最该修的一条。

**③「确认的话会增加运费行」**——确认送货单会把 transportFee 并入台账运输费用列；台账运输行的展开明细里能看到「送货单运费条目 + 独立运输单」两类来源。

## 二、运费方案建议

### 方案 A：保持载体，只补可解释性（改动最小）
- 「采购运费成本」列加来源明细弹框：运输单明细 + 送货单明细 + 「按口径推算 X 元（30元/吨×8.5吨）」三种来源分行展示；
- 口径分裂修复：`batchFreightCost` 走 ③ 推算时，把推算值同步写入批次聚合展示口径（或未付款基线口径对齐采购毛利率口径）。
- 送货单卡片仍显示采购运费（怪点保留）。

### 方案 B：采购运费升为批次级显式事实（推荐）
- 批次口径里新增/沿用 `supplyFreightPerTrip/PerTon` 推算出的**「本批采购运费」批次级值**，并允许直接填总额覆盖；
- 送货单卡片**不再展示采购运费**：AI 识别仍抽 transportFee，但落库后作为「该批运输事实的候选值」聚合到批次级（transport_note > 单据标注 > 口径推算的优先级不变，只是聚合点从送货单行上移到批次）；
- 台账「采购运费成本」列与「运输费用」列共用同一批次级来源，口径分裂自然消失；未付款基线与采购毛利率永远一致；
- 送货单卡片只剩销售运费（客户承担）——语义归位。
- 代价：structuredData.transportFee 的读点（LedgerService.batchFreightCost/deliveryFreightAmount、台账前端明细）要迁到批次级，存量送货单的 transportFee 需要兼容读取（老数据不迁移，读取时兜底）。

### 方案 C：运费按吨分摊进材料层（反对）
运费不是材料属性，分摊会污染采购吨价、破坏「点数只对货价」的口径，毛利全程对不上。不建议。

**推荐 B**，A 作为过渡也成立。注意都遵守：运费永远不进采购吨价、不进销售单价（点数只对货价）。

## 四、需要新增/适配

1. **对账状态字段**（上轮拍板遗留）：权威价导入后「已对账批次不自动重算」目前没做——系统无对账标志，现在是对所有受影响批次重算（人工绑定行不受影响）。要做需要先加批次级对账状态。
2. 材料表「送货销售金额」不含销售运费——列头注明口径即可（运费进销售总额但不进这张表）。
3. 材料清单无导出（低优先级）。
